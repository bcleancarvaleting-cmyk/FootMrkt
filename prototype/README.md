# MATCHX Play — clickable prototype

`matchx-play.html` is a single, self-contained page for trying ideas quickly. Open it in any browser — no server, database or install needed.

- All 92 clubs and 2,632 players with today's tiers and MX values (exported from the dev database).
- Sign-up offer: four league starters (7 + 4), three league picks, two Premier League Gold loans for 4 gameweeks.
- Weekly booster pack each new gameweek: put it on one player (colour border), one match, then it expires.
- Gifts from MATCHX to claim (a new one sometimes appears after a gameweek).
- Home-kit shirts and lookalike club badges, 
- Open packs, build a squad in any of the four formations, play a simulated gameweek with auto-subs and rewards, complete sets for MP credit, chat (bots reply), light/dark switch.
- Everything is saved in the browser's local storage; **Me → Start over** resets it.

It mirrors the real app's design and rules but is not connected to it: change it freely to explore ideas, then port what works into `src/`.
